# جستجوی هوشمند فارسی

یک سؤال می‌گیرد، در وب جواب‌های مرتبط را پیدا می‌کند، نتایج را به فارسی خلاصه می‌کند و لینک منبع‌ها را نشان می‌دهد.

## نحوه‌ی کار (همه رایگان، بدون کلید API)

1. **جستجو**: DuckDuckGo از طریق بسته‌ی `ddgs`. اگر سؤال فارسی باشد، ترجمه‌ی انگلیسی آن هم جستجو می‌شود تا منابع بین‌المللی هم دیده شوند.
2. **دریافت متن**: متن پاراگراف‌های هر صفحه با `requests` و `BeautifulSoup` گرفته می‌شود.
3. **خلاصه‌سازی**: روش استخراجی (انتخاب مهم‌ترین جمله‌ها بر اساس فراوانی کلمات و شباهت به سؤال). هیچ مدل هوش مصنوعی پولی‌ای استفاده نمی‌شود.
4. **ترجمه به فارسی**: `deep-translator` (مترجم رایگان گوگل، بدون کلید).

## نصب و اجرا

```bash
python -m venv .venv
source .venv/bin/activate        # در ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

سپس در مرورگر باز کنید: http://127.0.0.1:5000

## ساختار فایل‌ها

| فایل | کار |
|---|---|
| `app.py` | سرور Flask و صفحه‌ی اصلی |
| `index.html` | رابط کاربری (کادر جستجو و دکمه، راست‌به‌چپ) |
| `core.py` | ترکیب مراحل جستجو، خلاصه‌سازی و ترجمه |
| `searcher.py` | جستجوی وب و دریافت متن صفحه‌ها |
| `summarizer.py` | خلاصه‌سازی استخراجی و ترجمه |

## محدودیت‌ها

- سرویس‌های رایگان محدودیت نرخ دارند؛ اگر پشت سر هم زیاد جستجو کنید ممکن است موقتاً خطا بدهند.
- خلاصه‌ی استخراجی جمله‌ها را کپی و انتخاب می‌کند، نه اینکه بازنویسی کند؛ کیفیتش به متن منبع بستگی دارد.
- بعضی سایت‌ها دریافت خودکار را مسدود می‌کنند؛ در این حالت فقط از چکیده‌ی نتیجه‌ی جستجو استفاده می‌شود.
- مترجم رایگان غیررسمی است و ممکن است گاهی کار نکند؛ در این صورت متن اصلی نمایش داده می‌شود.

## قابلیت صوتی

- **گفتن سؤال (🎤):** تشخیص گفتار فارسی خود مرورگر (فقط Chrome یا Edge، نیاز به اینترنت). روی `https` یا `localhost` کار می‌کند.
- **شنیدن جواب (🔊):** صدای فارسی رایگان از طریق `edge-tts` (صدای «دلارا»؛ برای صدای مرد در `app.py` مقدار `TTS_VOICE` را `fa-IR-FaridNeural` کنید). اگر ساخته نشد، صدای خود مرورگر امتحان می‌شود.
- اگر سؤال را با میکروفون بگویید، جواب خودکار خوانده می‌شود. تیک «خواندن خودکار» برای سؤال‌های تایپی است.
- بعد از به‌روزرسانی حتماً دوباره بزنید: `pip install -r requirements.txt`

## ویدیوهای مرتبط

زیر پاسخ، چند ویدیوی مرتبط (از جستجوی ویدیوی DuckDuckGo، رایگان و بدون کلید) نمایش داده می‌شود. روی هر ویدیو بزنید؛ اگر یوتیوب باشد داخل صفحه پخش می‌شود و در غیر این صورت در تب جدید باز می‌شود. اگر یوتیوب بدون فیلترشکن باز نشود، لینک «در سایت اصلی باز کنید» زیر پخش‌کننده هست.

## انتشار روی اینترنت (Hugging Face Spaces، رایگان)

1. در huggingface.co حساب بسازید. (ممکن است فیلترشکن لازم باشد.)
2. بالا سمت راست: **New → Space**. یک اسم انگلیسی بدهید، **SDK = Docker**، قالب **Blank**، دسترسی **Public** و **Create Space** را بزنید.
3. **Files → Add file → Upload files**. همه‌ی فایل‌های داخل این پوشه (نه خود پوشه و نه zip) را بکشید و رها کنید و **Commit** بزنید. فایل `Dockerfile` باید در ریشه باشد.
4. چند دقیقه صبر کنید تا Building به Running برسد. آدرس سایت: `https://اسم‌کاربری-اسم‌اسپیس.hf.space`

محدودیت‌ها: سرویس رایگان بعد از مدتی بی‌کاری می‌خوابد (اولین باز شدن بعدی حدود یک دقیقه طول می‌کشد). هر IP در دقیقه ۱۲ جستجو و ۲۰ درخواست صدا می‌تواند بزند (در `app.py` قابل تغییر است).
